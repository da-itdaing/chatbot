# 판매자 챗봇 실험 기록

## 개요

판매자용 챗봇 테스트 실험 기록입니다.

## 평가 축

### LLM as Judge (5점 척도)

| 축 | 설명 |
|---|------|
| Task Fulfillment | 존 추천 요청에 적절한 존을 1~3개 추천했는가 |
| Grounded in Data | 실제 존재하는 존/상권 정보를 사용했는가 |
| Clarity | 간결하고 명확한 한국어 응답인가 |
| Commercial Accuracy | 상권 정보(유동인구, 임대료 등)가 정확한가 |
| Practical Value | 셀러에게 실질적으로 유용한 정보인가 |

### Latency 지표

| 지표 | 목표 |
|-----|------|
| P50 | < 3초 |
| P99 | < 8초 |
| Error Rate | < 1% |
